# Digital Clock - Multiple Time Zones

## Quick Start

### Web Version (Easiest)
```bash
1. Open index.html in any web browser
2. Clocks start displaying immediately
3. Done!
```

### Features
- ✅ Real-time clock for multiple cities
- ✅ Add/Remove cities easily
- ✅ 12-hour and 24-hour formats
- ✅ Show/hide seconds and date
- ✅ Dark and light themes
- ✅ Fully responsive design
- ✅ Works offline
- ✅ Remembers your preferences

### How to Use

1. **Add Cities**
   - Click "+Add City" button
   - Search for your desired city
   - Click to add

2. **Remove Cities**
   - Hover over a clock
   - Click the × button

3. **Customize**
   - Click "⚙️ Settings"
   - Change time format
   - Toggle theme (dark/light)
   - Show/hide seconds and date

4. **Default Cities**
   - New York
   - London
   - Dubai
   - India
   - Singapore
   - Tokyo
   - Sydney
   - Los Angeles

### Features Explained

**Time Format**
- 12-hour: Shows AM/PM (11:30:45 AM)
- 24-hour: Military format (23:30:45)

**Theme**
- Dark: Easy on eyes (default)
- Light: Traditional light background

**Show Seconds**
- ON: Display seconds (HH:MM:SS)
- OFF: Only show hours and minutes (HH:MM)

**Show Date**
- ON: Display full date below time
- OFF: Only show time

### Tips
1. Add cities relevant to your schedule
2. Use 24-hour format for international coordination
3. Dark theme is easier on eyes for long use
4. Search by country name or city name
5. Your preferences are saved automatically
